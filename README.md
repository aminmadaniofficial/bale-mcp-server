# Bale MCP Server 🚀

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python Version](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![Model Context Protocol](https://img.shields.io/badge/MCP-Standard-purple.svg)](https://modelcontextprotocol.io/)

A high-performance **Model Context Protocol (MCP)** server that enables Large Language Models (LLMs) like Claude, ChatGPT, Gemini, and Antigravity agents to seamlessly connect to and interact with **Bale Messenger** user accounts.

Built natively on top of [`aiobale-py`](https://github.com/aminmadaniofficial/aiobale) and the official Python MCP SDK.

---

## ✨ Features

- 🔐 **Multi-Session Account Management:** Connect to pre-existing `.bale` sessions or authenticate interactively via SMS/2FA.
- 💬 **Complete Messaging Tools:** Send, reply, edit, delete, forward, and pin messages across private chats, groups, and channels.
- 📜 **Chat & Dialog Inspection:** Retrieve recent dialogs, unread counts, and paginate through message histories.
- 👥 **Contacts & Users:** Search users by username or phone number, fetch profiles, manage contacts, and handle blocklists.
- 📢 **Groups & Supergroups:** Inspect group details, view member lists, create groups, and manage participant permissions.
- ⚡ **Reactions & Status:** Send emoji reactions and trigger typing presence indicators.
- 🛡️ **Zero Data Leakage:** Session credentials (`.bale`) are safely stored locally and excluded from version control.

---

## 📦 Architecture

```
LLM Client (Claude Desktop / Cursor / Antigravity / Cline)
                │
                │  JSON-RPC (STDIO / SSE)
                ▼
        Bale MCP Server (mcp.server.mcpserver)
                │
        Client Connection Pool
                │
       aiobale Async Client (WebSockets / Protobuf / gRPC)
                ▼
        Bale Messenger Network
```

## 🚀 Quick Start

### 1. Installation

Clone the repository and install dependencies using `uv` (recommended) or `pip`:

```bash
git clone https://github.com/aminmadaniofficial/bale-mcp-server.git
cd bale-mcp-server

# Create virtual environment and install dependencies
uv venv
source .venv/bin/activate
uv pip install -e .
```

### 2. Session Setup

Copy existing `.bale` session files (generated by `aiobale login` or your bot workflow) into the `./sessions/` directory, or use the interactive login CLI:

```bash
bale-mcp login --phone 989XXXXXXXXX
```

### 3. Running the Server

Run the MCP server over standard input/output (STDIO):

```bash
bale-mcp run
```

## 🛠️ MCP Configuration

Add the server to your MCP client configuration (e.g. `claude_desktop_config.json` or Antigravity `mcp_config.json`):

```json
{
  "mcpServers": {
    "bale": {
      "command": "uv",
      "args": [
        "--directory",
        "/absolute/path/to/bale-mcp-server",
        "run",
        "bale-mcp",
        "run"
      ],
      "env": {
        "BALE_SESSIONS_DIR": "/absolute/path/to/bale-mcp-server/sessions"
      }
    }
  }
}
```
